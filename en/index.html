Client work · Confidential

Sales & ad automation

  1. 01

    How it started

    I was looking for a project to complete my studies when I met a business owner with a real problem. Most of his week went into going through cold-call lists, hunting for the customers who actually needed one specific product he sells.

  2. 02

    Imagine

    He pictured AI agents doing that search for him, and brought me in to build it. Our first version ran fully on AI agents, just as planned, but we soon saw how much it would cost to run. So we changed course: Playwright now does the heavy lifting of browsing and collecting data cheaply, and the AI agents only step in where judgement and writing are needed.

  3. 03

    Structure & build

    The system is written in TypeScript on Node.js, with Express serving a small web interface and API. Playwright drives a real browser to gather information from the web. A team of AI agents on the Claude and OpenAI APIs splits the work: one researches each business, one judges whether it needs what the client offers, and one writes the outreach email.

    Jobs run in the background, data is stored in PostgreSQL (SQLite while developing), tests run on Vitest, and the whole thing ships as a Docker container.

    • TypeScript
    • Node.js
    • Express
    • Playwright
    • Claude API
    • OpenAI API
    • PostgreSQL
    • Docker
  4. 04

    How it came out

    I had never built custom AI agents before. Within a month there was a working demo: it finds businesses with a real need, matches them to the right offer and has the email draft ready, all automatically.

    Switching to Playwright plus AI agents brought the running costs down to almost nothing. It frees up his week to grow revenue, and it finds far more matching customers than the cold-call lists did.

Confidential, so no code or link
Website + store

kasaan.fi

  1. 01

    How it started

    When Kasaan started 3D printing, we needed a landing page to tell people about it, so I made one.

  2. 02

    Imagine

    We quickly realised we needed more than a landing page. Along the way we had made a lot of useful prints, and a web store would let people buy them. So I decided to make it happen.

  3. 03

    Structure & build

    The front end is React with Vite, prerendered to static HTML so search engines and AI tools can read every page, in Finnish, English and Swedish.

    Behind the store is a PHP 8 REST API on MySQL that I built from scratch, grown through 13 database migrations so far. It handles products, orders, PDF invoices and credit notes, customer accounts with Google sign-in, and an admin panel with two-factor login. Playwright tests check the layout on phones, and GitHub Actions deploys every push to a staging site, with production one click away.

    • React
    • Vite
    • PHP 8
    • MySQL
    • REST API
    • Playwright
    • GitHub Actions
  4. 04

    How it came out

    kasaan.fi is live with quote requests and an online store in three languages. It replaced an earlier React site I built for Kasaan in 2025.
